# Backup Policy (Draft)

실운영 계정 없이 먼저 확정할 수 있는 백업 정책 초안입니다.

## 1) 백업 대상

- PostgreSQL 데이터 (`sp`)
- 중요 운영 문서 (`docs/*.md`)
- 배포 설정 파일 (`docker-compose*.yml`, `infra/nginx/*`)

## 2) 권장 주기

- DB 전체 덤프: 1일 1회
- 트랜잭션 중요 구간: 필요 시 추가 스냅샷
- 설정 파일: 변경 시점마다 Git 태그/릴리즈로 보존

## 3) 보관 정책

- 일간 백업 14일
- 주간 백업 8주
- 월간 백업 6개월

## 4) 복구 점검

- 월 1회 복구 리허설
- 복구 시간 목표(RTO)와 데이터 손실 허용치(RPO) 기록

## 5) 추후 실운영 연동 시 필요한 값

- 백업 저장소 접속 정보
- 암호화 키 관리 정책
- 자동 백업 실행 계정/권한
