# 운영 롤백 런북

## 1) 롤백 트리거

- 배포 직후 5xx 급증
- 관리자 핵심 API(`leads`, `stats`, `activity`) 오류 지속
- 응답 시간 급증으로 운영 기준 미달

## 2) 즉시 조치

1. 신규 배포 트래픽 차단
2. 직전 정상 릴리스로 애플리케이션 롤백
3. 모니터링 알림 지속 여부 확인

## 3) 데이터베이스 정책

- Prisma 마이그레이션은 자동 다운그레이드를 지원하지 않으므로,
  롤백 전 백업/스냅샷을 기준으로 복구 전략을 사용한다.
- 문제 마이그레이션은 `prisma migrate resolve`로 상태 정리 후 후속 수정 마이그레이션 적용.

## 4) 애플리케이션 롤백 체크

- Web: 직전 빌드 아티팩트 재배포 후 `/`, `/consult`, `/admin/login` 확인
- API: `/api/v1/admin/auth/me`, `/api/v1/admin/leads`, `/api/v1/admin/leads/stats` 200 확인
- 활동 피드: `/api/v1/admin/leads/activity?limit=20&page=1` 정상 확인

## 5) 장애 종료 기준

- 오류율/응답시간이 배포 전 기준으로 회복
- 관리자 핵심 플로우(조회/상태변경/CSV) 정상
- 원인 및 재발 방지 항목 기록 완료

## 6) 사후 조치

- 장애 타임라인 기록
- 원인 PR/커밋 범위 확정
- 재발 방지 테스트/모니터링 항목 추가
