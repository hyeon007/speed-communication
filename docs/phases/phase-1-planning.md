# Phase 1 — 기획 & 설계 (Week 1)

## 1) 브랜드/메시지 정의
- 사이트명: `모바일셀렉트`
- 핵심 메시지: "복잡한 휴대폰 선택, 전문가가 빠르게 맞춤 상담"
- 톤앤매너: 미니멀, 신뢰, 고급, 과장 없는 문구

## 2) 타겟 고객
- 실속형 직장인(요금 최적화)
- 얼리어답터(최신기기 빠른 상담)
- 가족 결합형 고객(다회선 통합 상담)

## 3) 사이트맵
- `/` 홈
- `/devices` 기기 소개
- `/plans` 요금/혜택
- `/compare` 비교
- `/consult` 상담 신청 (핵심)
- `/faq` 자주 묻는 질문

## 4) 전환 구조
- 상단 고정 CTA: 전화 상담
- 섹션별 CTA: "무료 상담 신청"
- 폼 최소 입력: 이름/연락처/관심기기/희망시간/동의

## 5) 디자인 시스템 초안
- Color: `#0B0B0C`, `#121316`, `#F5F7FA`, `#4DA3FF`
- Typeface: Pretendard + Inter
- Spacing: 4px 기반 scale

## 완료 기준 (Definition of Done)
- [ ] 브랜드 메시지 확정
- [ ] 페이지 구조 확정
- [ ] CTA 문구 확정
- [ ] 폼 필드 확정
- [ ] 디자인 토큰 승인
