# Monitoring Baseline

실운영 비밀번호 없이 먼저 정할 수 있는 모니터링 기준 문서입니다.

## 1) 목표 지표

- 가용성: Nginx `/healthz` 5분 평균 성공률
- 응답시간: API p95, p99
- 에러율: API 5xx 비율, 앱 예외 로그 건수

## 2) 수집 대상

- Nginx access/error 로그
- API 애플리케이션 로그 (Nest logger)
- 컨테이너 리소스(CPU/MEM)

## 3) 알림 기준(초기안)

- 5xx 비율 5분 평균 > 2%
- API p95 > 800ms (10분 지속)
- `api` 또는 `nginx` 컨테이너 재시작 횟수 급증

## 4) 최소 운영 루틴

- 배포 직후 15분 로그 집중 확인
- 일간: 에러 요약/응답시간 추세 확인
- 주간: 재시작/용량/알림 임계값 재점검

## 5) 추후 실운영 연동 시 필요한 값

- 알림 채널(Slack/Email/Webhook) 인증정보
- APM/로그 스택 접속 토큰
- 대시보드 접근 계정
