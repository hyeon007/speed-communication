## Description

[Nest](https://github.com/nestjs/nest) framework TypeScript starter repository.

## Project-specific quick guide

### 1) Environment

```bash
cp .env.example .env
```

- `LEAD_STORAGE=memory`: 인메모리 저장(기본)
- `LEAD_STORAGE=prisma`: PostgreSQL + Prisma 저장

### 2) Prisma commands

```bash
npm run prisma:generate
npm run prisma:validate

# 개발 환경에서 스키마 반영(빠른 반영)
npm run prisma:push

# 운영/스테이징 환경에서 마이그레이션 반영(권장)
npm run prisma:migrate:deploy
```

### 3) Admin auth flow

- 로그인: `POST /api/v1/admin/auth/login`
- 역할:
  - `editor`: 조회/개별 수정/일괄 변경 가능
  - `operator`: 조회/개별 수정 가능(일괄 변경 제한)
  - `viewer`: 조회 전용
- 보호된 API:
  - `GET /api/v1/admin/leads`
  - `PATCH /api/v1/admin/leads/:id/status`
  - `PATCH /api/v1/admin/leads/:id/memo`

`GET /api/v1/admin/leads` 쿼리 파라미터:

- `search` (선택): 이름/전화/관심기기/시간 검색
- `status` (선택): `new | in_progress | completed`
- `page` (선택, 기본 1)
- `pageSize` (선택, 기본 10, 최대 50)
- `startDate` (선택): ISO date/date-time
- `endDate` (선택): ISO date/date-time
- `sortBy` (선택): `createdAt | name | status` (기본 `createdAt`)
- `sortDirection` (선택): `asc | desc` (기본 `desc`)

인증 헤더 예시:

```http
Authorization: Bearer <accessToken>
```

## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Run tests

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```

## Deployment

When you're ready to deploy your NestJS application to production, there are some key steps you can take to ensure it runs as efficiently as possible. Check out the [deployment documentation](https://docs.nestjs.com/deployment) for more information.

If you are looking for a cloud-based platform to deploy your NestJS application, check out [Mau](https://mau.nestjs.com), our official platform for deploying NestJS applications on AWS. Mau makes deployment straightforward and fast, requiring just a few simple steps:

```bash
$ npm install -g @nestjs/mau
$ mau deploy
```

With Mau, you can deploy your application in just a few clicks, allowing you to focus on building features rather than managing infrastructure.
